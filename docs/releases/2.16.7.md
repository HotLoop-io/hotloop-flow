HotLoop Flow 2.16.7 puts the help for every node in all 14 languages the editor speaks. Before, most of the node help and the notes on how a node differs from Node-RED showed in English in the other 13. Nothing in your flows, settings or chart changes.

## What changed

- **Every node's help is translated.** The help text, field notes and "how this differs from Node-RED" notes for all nodes now read in Spanish, French, Italian, German, Norwegian (Bokmal), Bulgarian, Greek, Korean, Japanese, Vietnamese, Hindi, Simplified Chinese and Arabic. Arabic stays laid out right to left. The 13 lists of nodes still showing English are empty. Node type names, protocol and product names, property names, and anything inside backticks stay as they are, so a flow file reads the same in every language.
- **Plain wording from one shared glossary.** Each language uses the same terms for node, message, flow, tag and the rest that the editor already used, so the help matches the screen it sits beside.
- **Internal cleanup with no effect on a running Flow.** The 26 low confidence lists, which only two catalog tests read and nothing in the product did, are gone, along with the two checks and the paragraph about them in the language docs.

## New settings

None.

## Upgrade

A plain `helm upgrade` to the 2.16.7 image and chart, or the new tag in your Quadlet unit. Nothing happens on first start and nothing needs migrating. A flow file loads and saves byte for byte as before. This release builds the amd64 image. The `2.16` and `2` tags keep the arm64 image they already hold from 2.16.1, and a small follow-up release with nothing else in it brings arm64 back. If you are on arm64, stay on 2.16.1 until then.

## What isn't proven

The translations were written from the shared glossary and checked by the catalog tests (the same keys, the same code spans, no untranslated sentences left). No native speaker has read them, so a phrase may read stiffly in a language you know well.
