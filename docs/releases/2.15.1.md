HotLoop Flow 2.15.1 is 2.15.0 with the arm64 image added, and nothing else. 2.15.0 shipped amd64 only so it could get to production and read stable first, and this is the one small bump that builds both. There is no change to the code, the chart, the settings or your flows.

## What changed

- The image is built for linux/amd64 and linux/arm64. The `2.15.1`, `2.14` and `2` tags hold both.
- The README and the install pages name 2.15.1 and say amd64 and arm64.

## New settings

None.

## Upgrade

A plain `helm upgrade` to the 2.15.1 image and chart, or the new tag in your Quadlet unit. If you are on arm64 and stayed on 2.14.1 while 2.15.0 was amd64 only, this is your move to FlowLab's database sink, replay and the 13 languages: read the 2.15.0 notes for what they are and what isn't proven. Nothing happens on first start and nothing needs migrating.

## What isn't proven

The arm64 image is built under emulation on the runner, and it starts and reports its version in the release run. It has not been run on an arm64 box for this release.

Image: `ghcr.io/hotloop-io/hotloop-flow:2.15.1`, linux/amd64 and linux/arm64. Chart: `https://hotloop.io/hotloop-flow/`. The README at this tag has the rest, with pictures: https://github.com/HotLoop-io/hotloop-flow/blob/v2.15.1/README.md
